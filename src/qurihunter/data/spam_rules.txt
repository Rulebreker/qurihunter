# Every drop is logged with the rule that fired. Lines:  kind: value        (# starts a comment)
#   url:    regex searched in the full URL            host:  regex searched in the host
#   path:   regex searched in the URL path            title: regex searched in the title
#   word:   comma separated words (whole word, case-insensitive) searched in title + snippet + URL
#   script: maximum share (0-1) of non-Latin letters in the title for a Latin-script dork
# A page whose path clearly names a disclosure/bounty policy is exempt from the soft path/host rules (not from url/word/script).
